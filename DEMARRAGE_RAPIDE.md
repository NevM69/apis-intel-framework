# 🐝 Apis Intel Core Framework - Guide Local

Félicitations pour le téléchargement du framework Apis Intel !

## 🚀 Étapes d'installation sur votre machine :

1. Assurez-vous d'avoir Node.js (version 18, 20 ou 22+) installé sur votre machine.
2. Ouvrez un terminal dans ce dossier :
   ```bash
   npm install
   ```

3. Pour lancer un cas d'investigation :
   ```bash
   npx tsx examples/01-basic-case.ts
   ```

4. Pour lancer la détection automatisée de contradictions juridiques :
   ```bash
   npx tsx examples/02-contradiction-check.ts
   ```

5. Pour tester la balise disparition inquiétante ONG :
   ```bash
   npx tsx examples/03-missing-person-beacon.ts
   ```

---
Conçu avec les directives Zero Data Retention (ZDR) et le Protocole d'Investigation LEO d'Apis Intel.
